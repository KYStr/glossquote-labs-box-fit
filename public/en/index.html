Calculation and limits

Does this find the optimal 3D packing arrangement?

No. It compares one uniform grid for each listed axis-aligned orientation. It does not mix orientations or search remaining space.

Does rotation mean any angle is allowed?

No. It only permutes the item's length, width and height along the box axes. You must account for labels, fragility and shape constraints yourself.

How is the gap applied?

The gap is added only between adjacent items along each box axis. No clearance is added between an item and a box wall.

Does the result guarantee that everything will fit physically?

No. The calculation does not check shape, tolerances, flexible packaging, weight, handling room or box strength.
